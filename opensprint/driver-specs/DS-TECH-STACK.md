## Constraint

The following technology choices are non-negotiable:

- **NestJS** — HTTP API framework
- **MongoDB** — Primary data store (source of truth)
- **Kafka** — Event publishing / message broker
- **Elasticsearch** — Full-text search

Code must follow SOLID principles and DDD practices.
