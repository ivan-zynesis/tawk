## Question

What consistency guarantee do we provide between MongoDB writes and Kafka event publishing?

## Decision

Best-effort publish. The write path is:
1. Write message to MongoDB (source of truth)
2. Publish `message-created` event to Kafka
3. If Kafka publish fails, log the error but return success to the client

MongoDB is authoritative. Elasticsearch may temporarily lag or miss events.

## Alternatives Considered

| Option | Pros | Cons |
|---|---|---|
| Transactional outbox | Guaranteed delivery | Added complexity, polling/tailing process |
| Change Data Capture (CDC) | Decouples API from Kafka | Operational complexity, connector management |
| **Best-effort publish** | Simplest, fast write path | ES can drift from MongoDB |

## Rationale

We took this path for simplicity by consciously setting "transactional outbox" as out-of-scope for this exercise.
